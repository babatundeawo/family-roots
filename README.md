# Family Roots

A private place to record your family tree, keep the stories and traditions behind each person, and invite relatives to add what they remember.

[![Deploy](https://github.com/babatundeawo/family-roots/actions/workflows/deploy.yml/badge.svg)](https://github.com/babatundeawo/family-roots/actions/workflows/deploy.yml)

## What it does
- A family tree you build person by person, with a search by name or place and a timeline of births and passings
- Room for each person's birthplace and story
- Shared trees with owner, editor and viewer roles, joined through invite links
- Email and Google sign-in
- Print the tree as an outline, or download a backup of everything
- Installs on phones like an app, works in light or dark, and keeps trees you opened readable offline

## Using it
1. Create an account or sign in.
2. Create a tree and add your oldest known ancestor.
3. Add children by choosing a parent.
4. Use **Invite** to send relatives a link as editors or viewers.

## Built with
Vanilla JavaScript, esbuild, Firebase Authentication, Cloud Firestore and Firebase Hosting, built and deployed by GitHub Actions.
