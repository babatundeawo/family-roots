# Customising
- **Colors, fonts, spacing:** `public/styles.css`, the "Design tokens" block at the top. Dark theme colours are under `:root[data-theme=dark]`.
- **Text:** `public/app.js` (screens) and `public/index.html` (title, description).
- **Icons / logo:** replace `public/icons/icon-192.png` and `icon-512.png` (same names and sizes).
- **App name and colours when installed:** `public/manifest.json`.
Edit any file on GitHub with the pencil icon, then **Commit changes**.
